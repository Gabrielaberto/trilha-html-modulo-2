# 🏥 Clínica Vida Plena

Projeto desenvolvido como parte do desafio **"Criando um Site Completo com HTML"** da trilha **HTML I - Conceitos Básicos** da DIO (Digital Innovation One).

---

## 📖 Sobre o Projeto

O objetivo deste desafio foi construir um site institucional para uma clínica médica utilizando os conceitos fundamentais de HTML apresentados no módulo.

Para este projeto foi criada a **Clínica Vida Plena**, uma clínica fictícia voltada ao atendimento humanizado e ao cuidado integral da saúde.

O site foi estruturado em quatro páginas:

- 🏠 Página Principal
- ℹ️ Sobre a Clínica
- 📅 Horário de Atendimento
- 📞 Contato

Todas as páginas seguem o mesmo padrão visual, contendo:

- Menu lateral de navegação
- Cabeçalho com imagem temática
- Área de conteúdo
- Rodapé com informações de contato

---

## 🚀 Tecnologias Utilizadas

- HTML5
- CSS3

## ✅ Recursos Implementados

### Estrutura de Conteúdo

- Títulos e subtítulos
- Parágrafos
- Links de navegação
- Listas ordenadas e não ordenadas

### Formatação de Texto

- Negrito (`strong`)
- Itálico (`i`)
- Separadores (`hr`)

### Mídias

- Imagens em todas as páginas
- Integração com Google Maps via iframe

### Tabelas

- Horários de atendimento por especialidade

### Formulários

- Campo Nome
- Campo E-mail
- Campo Assunto
- Área de Mensagem
- Checkboxes
- Lista de seleção (select)
- Botões de envio e limpeza

---

## 🏠 Página Principal

A página inicial apresenta uma breve descrição da Clínica Vida Plena, seus diferenciais e as especialidades disponíveis, além de servir como ponto de navegação para as demais áreas do site.

---

## ℹ️ Sobre a Clínica

A página institucional contém informações sobre a história da clínica, sua missão, visão, valores e equipe profissional.

---

## 📅 Horário de Atendimento

Nesta página são apresentados os serviços oferecidos e uma tabela contendo os horários de funcionamento de cada especialidade.

---

## 📞 Contato

A página de contato reúne:

- Telefones para atendimento
- Endereço da clínica
- Localização por meio do Google Maps
- Formulário de contato
- Seleção de especialidades de interesse

---

## 🎯 Objetivo de Aprendizagem

Este projeto permitiu praticar conceitos fundamentais para o desenvolvimento web, incluindo:

- Estruturação de documentos HTML
- Navegação entre páginas
- Organização de conteúdo
- Criação de formulários
- Utilização de tabelas
- Inserção de imagens e iframes
- Aplicação de estilos com CSS
